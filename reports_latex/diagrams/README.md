# LaTeX figures (1.3–1.10)

Publication-oriented **TikZ** / **pgfplots** sources for the thesis figure briefs under `diagrams/figure_1_*.md`.

## Layout

| Path | Purpose |
|------|---------|
| `tex/` | `fig_1_3.tex` … `fig_1_10.tex`, shared `dars-fig-preamble.tex` |
| `data/` | CSV consumed by pgfplots (generated by script + committed fallbacks) |
| `pdf/` | Build output (`latexmk` / `pdflatex` writes here) |
| `scripts/` | `export_plot_data.py` — refresh CSV from `benchmark_runs/` |
| (root) | `all_figures.tex`, `build.ps1` — gallery + batch build |

## Prerequisites

- **MiKTeX** or **TeX Live** on Windows with **`latexmk` or `pdflatex`** on `PATH` (`build.ps1` prefers `latexmk`, then falls back to two-pass `pdflatex`).
- LaTeX packages: `standalone`, `tikz`, `pgfplots`, `pgfplotstable`, `booktabs`, `microtype`, `helvet`, `xcolor`, `amsmath`.

## Build

From this directory (`reports_latex/diagrams`):

```powershell
.\build.ps1
```

Optional: refresh plot CSV from repository metrics first:

```powershell
python scripts\export_plot_data.py
.\build.ps1
```

## Single figure

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=pdf tex\fig_1_3.tex
```

## Review sheet

After individual PDFs exist, compile the gallery from this directory:

```powershell
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=pdf all_figures.tex
```

(`all_figures.tex` lives next to `build.ps1`; it includes graphics from `pdf/`.)

## Troubleshooting

- **`xticklabels from table`:** requires a recent `pgfplots`; regenerate data with `python scripts\export_plot_data.py`.
- **Figure 1.9 (`varwidth`):** needs a reasonably complete TeX install (not a bare minimal scheme).

## Notes

- Figures **1.7** / **1.8** use `data/*.csv`. If files are missing, run `export_plot_data.py` or keep the bundled CSVs (from `benchmark_runs/paper_final/` when present).
- **1.10** is explicitly **schematic** (no telemetry half-lives claimed).
